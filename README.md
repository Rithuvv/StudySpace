# 📚 StudySpace

**StudySpace** is a student productivity and study-tracking website designed to help students organize their studies, manage daily tasks, stay consistent, and track academic progress in one place.

## ✨ Features

* ⏱️ **Pomodoro Timer**
  Focus using dedicated study sessions with short and long breaks.

* ✅ **To-Do List**
  Add, manage, and complete daily study tasks.

* 🔥 **Study Streak Tracker**
  Track consistent study habits and stay motivated.

* 📊 **Marks Tracker**
  Record previous marks and monitor academic performance.

* 📚 **Books & Resources**
  Keep books, learning materials, and useful resources organized.

* 💡 **Motivational Interface**
  Designed to make studying more engaging and encourage consistency.

* 🎨 **Clean & Modern UI**
  A simple interface that keeps study management easy and organized.

# 🚀 Project Setup

Follow the steps below to run StudySpace locally.

### Prerequisites

Make sure you have the following installed:

* Node.js
* npm
* Git

Check your installations using:

```bash
node -v
npm -v
git --version
```

### 1. Clone the Repository

```bash
git clone https://github.com/Rithuvv/StudySpace
```

Navigate into the project folder:

```bash
cd StudySpace
```

### 2. Install Dependencies

```bash
npm install
```

This installs all the dependencies required to run the project.

### 3. Start the Development Server

```bash
npm run dev
```

Vite will provide a local development URL, usually:

```text
http://localhost:5173/
```

Open the URL in your browser to access StudySpace.

# 📖 Usage Instructions

### To-Do List

1. Open the To-Do section.
2. Add the study tasks you need to complete.
3. Mark tasks as completed once finished.
4. Use the list to organize your daily study goals.

### Pomodoro Timer

1. Open the Pomodoro Timer.
2. Start a study session.
3. Pause or resume the timer when required.
4. Take short or long breaks between study sessions.

### Study Streak

Use the streak tracker to monitor your consistency and maintain regular study habits.

### Marks Tracker

Add your previous academic marks to keep track of your performance and monitor your progress.

### Books & Resources

Add books and useful learning resources to keep your study materials organized in one place.

